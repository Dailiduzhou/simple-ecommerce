# Third-party images the test stack needs, and the repository each one is
# mirrored to under <ACR_REGISTRY>/<ACR_NAMESPACE>. The test server cannot reach
# Docker Hub; CI copies every entry into ACR before deploying
# (.github/scripts/mirror-images.sh), and docker-compose.registry.yml points the
# stack at these repositories instead of the public originals.
#
# Keep the source tag identical to the one in docker-compose.yml,
# docker-compose.caddy.yml or docker-compose.dev.yml; deploy tests enforce it.
# Sources are Docker Hub references. Keep them free of a registry port so the
# script can drop the tag by removing everything after the last colon.
#
# A mirrored tag is never refreshed automatically. Bump the version here (and in
# Compose) to publish a new ACR tag; upstream floating tags such as
# postgres:16-alpine intentionally stay at the first mirrored content.
